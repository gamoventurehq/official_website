## Priority Issues

### [P1] Inert Click State on Advisory Capability Cards
- **What**: In `components/CapabilitiesSection.tsx`, the capability `<article>` cards have an `onClick` handler and `cursor: pointer` without keyboard accessibility (`tabIndex={0}`, `role="button"`) or visible accordion expansion.
- **Why it matters**: Sighted users click expecting an expanded view and get no visual feedback; keyboard/screen-reader users encounter an inaccessible interactive element.
- **Fix**: Either implement an expandable accordion drawer revealing deep-dive case studies or remove the inert `onClick` and `cursor: pointer`.
- **Suggested command**: `$impeccable layout` / `$impeccable polish`

### [P2] Missing Scroll Lock on Mobile Navigation Drawer
- **What**: In `components/Navbar.tsx`, when the full-screen mobile menu drawer is opened (`mobileMenuOpen === true`), the background page remains scrollable.
- **Why it matters**: On mobile touchscreens, background scrolling behind the open drawer causes disorientation and visual stutter.
- **Fix**: Add a `useEffect` hook to set `document.body.style.overflow = "hidden"` when `mobileMenuOpen` is active, and add an `Escape` key dismissal listener.
- **Suggested command**: `$impeccable adapt` / `$impeccable harden`

### [P3] Small-Text Monospace Contrast Optimization
- **What**: In `app/globals.css`, `--text-dim` (`#78716c`) on `#1C1917` provides a ~3.4:1 contrast ratio on 10px–11px monospace sub-labels (e.g. `.hologram-foot-stats`).
- **Why it matters**: Fails WCAG AA minimum contrast (4.5:1) for small text in high-glare environments.
- **Fix**: Lighten `--text-dim` from `#78716c` to `#948e88` or `#a8a29e`.
- **Suggested command**: `$impeccable polish` / `$impeccable colorize`
